TableSage RPG is a Python terminal application that turns tabletop RPG session recordings into transcripts, session summaries, and campaign records. This page walks you through every dependency, the TableSage installation command, and first-launch configuration so you finish with a working setup ready to process your first recording.

## Prerequisites

Before you install TableSage, make sure you have the following ready.

**Tools you will install:**

- **uv** — manages Python and installs TableSage; also downloads Python 3.12 for you if needed
- **Git** — fetches the TableSage source during installation and updates
- **FFmpeg** — provides both `ffmpeg` and `ffplay` for audio processing and playback

**API keys you will need:**

- An **ElevenLabs** API key — required for transcription and speaker diarization in every session
- An API key for **at least one** of OpenAI, Anthropic, or Google Gemini — the default model choices use OpenAI and Anthropic, but you can select a single provider in Settings

<Warning>
  Installing TableSage downloads large machine-learning dependencies, including PyTorch and local voice-recognition models. Expect the initial installation to take several minutes and require approximately **8 GB of free disk space** on Linux and Windows (somewhat less on macOS).
</Warning>

### Storage Requirements

Plan for the following approximate storage needs before you begin:

| Material | Size |
| --- | --- |
| TableSage and its machine-learning libraries | 8 GB (less on macOS) |
| Downloaded models | 0.5 GB |
| Each Session's audio | 230 MB per hour of recording |
| Each Player's voice samples | Tens to a few hundred megabytes |

## Install Dependencies

<Steps>

  <Step title="Install uv">
    [uv](https://docs.astral.sh/uv/) installs and runs TableSage. It also downloads and manages the Python version TableSage needs, so you do not have to install Python separately first.

    <Tabs>
      <Tab title="macOS / Linux">
        ```sh
        curl -LsSf https://astral.sh/uv/install.sh | sh
        ```
      </Tab>
      <Tab title="Windows (PowerShell)">
        ```powershell
        powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
        ```
      </Tab>
    </Tabs>

    Restart your terminal after the installer finishes, then confirm uv is available:

    ```sh
    uv --version
    ```

    If the installer offers to add uv to your `PATH`, accept. If `uv --version` still fails after restarting the terminal, follow the `PATH` instructions the installer printed.

    **Optional: download Python ahead of time**

    TableSage requires Python 3.12 or newer. uv uses a suitable existing installation or downloads one automatically when you install TableSage. If you prefer to download Python 3.12 yourself first, run:

    ```sh
    uv python install 3.12
    ```

    By default this adds a versioned Python executable and leaves your shell's `python` command unchanged. TableSage's dependencies stay isolated in their own [tool environment](https://docs.astral.sh/uv/concepts/tools/#tool-environments).
  </Step>

  <Step title="Install Git">
    The installation command uses Git to fetch the TableSage application. If Git is not already installed, follow the [Git installation instructions](https://git-scm.com/install/) for your operating system and make sure Git is added to your `PATH`. Restart your terminal, then check:

    ```sh
    git --version
    ```

    This command must succeed before you install or update TableSage.
  </Step>

  <Step title="Install FFmpeg">
    TableSage checks for both `ffmpeg` and `ffplay` at startup and exits with an error if either is missing. Install an FFmpeg distribution that provides both commands.

    <Tabs>
      <Tab title="Ubuntu / Debian">
        ```sh
        sudo apt install ffmpeg
        ```
      </Tab>
      <Tab title="macOS (Homebrew)">
        ```sh
        brew install ffmpeg
        ```
      </Tab>
      <Tab title="Windows">
        Download an FFmpeg build from the [FFmpeg download page](https://ffmpeg.org/download.html) and add its `bin` directory to your `PATH`. Restart your terminal after updating the `PATH`.
      </Tab>
    </Tabs>

    Restart your terminal, then confirm that both commands are available:

    ```sh
    ffmpeg -version
    ffplay -version
    ```

    Both must succeed. A build that ships `ffmpeg` without `ffplay` will not satisfy TableSage's startup check.
  </Step>

  <Step title="Install TableSage">
    With uv, Git, and FFmpeg in place, install TableSage directly from its GitHub repository:

    ```sh
    uv tool install git+https://github.com/erik-saltwell/tablesage.git
    ```

    This step downloads large machine-learning dependencies, so give it time. It installs two equivalent commands, `tablesage` and `tablesage-rpg`; either one starts the application. If uv asks to add its tools directory to your `PATH`, accept that change and restart your terminal before continuing.

    **To update TableSage later**, run:

    ```sh
    uv tool install --upgrade git+https://github.com/erik-saltwell/tablesage.git
    ```
  </Step>

  <Step title="Create and Open a Workspace">
    Choose or create a directory for your TableSage data, then start the application from inside it. TableSage always uses the directory you launch it from, so start it from this workspace every time.

    <Tabs>
      <Tab title="macOS / Linux">
        ```sh
        mkdir -p ~/Documents/tablesage
        cd ~/Documents/tablesage
        tablesage-rpg
        ```
      </Tab>
      <Tab title="Windows (PowerShell)">
        ```powershell
        mkdir $HOME\Documents\tablesage
        cd $HOME\Documents\tablesage
        tablesage-rpg
        ```
      </Tab>
      <Tab title="Windows (cmd.exe)">
        ```bat
        mkdir "%USERPROFILE%\Documents\tablesage"
        cd /d "%USERPROFILE%\Documents\tablesage"
        tablesage-rpg
        ```
      </Tab>
    </Tabs>

    On the first launch, TableSage creates a `.tablesage/` folder in the workspace and opens the Welcome screen with the message: *Configure and save your settings before progressing. Press S to open Settings.* The **Campaigns** and **Players** options are disabled until you save settings — this is expected.
  </Step>

  <Step title="Configure Your API Keys and Models">
    After launching TableSage, press **S** to open Settings.

    Enter your API keys and choose your language models. Settings asks for three model tiers — **High**, **Medium**, and **Low** — so you can assign a stronger model to demanding tasks and a cheaper, faster one to simpler work.

    **Which keys you need:**

    - **ElevenLabs** is always required; it handles transcription and speaker diarization for every session you import.
    - **Anthropic**, **OpenAI**, and **Gemini** keys are only required for the providers named in your selected model IDs.

    **Default model tiers and their uses:**

    | Tier | Default | Used for |
    | --- | --- | --- |
    | **High** | `openai/gpt-6-astra` | Session artifacts, regeneration, Previously On and Opportunities |
    | **Medium** | `anthropic/claude-sonnet-4-5` | Glossary extraction, spellcheck, new-player name corrections and speech proposals |
    | **Low** | `anthropic/claude-haiku-4-5` | Remove Bad Utterances |

    Model IDs must use the form `provider/model-name`, where the provider is exactly `anthropic`, `openai`, or `gemini`. Each tier field offers a dropdown of bundled presets across all three providers, plus a **Custom…** option if you want a different model from one of those providers.

    When you are done, choose **Continue** to save — or move focus out of a key field and press **C**. Saving validates your model IDs, tests each configured model, and downloads local audio-processing models if they are not already installed. This may take a while on first save.
  </Step>

</Steps>

## Troubleshooting

If TableSage does not start or behaves unexpectedly after installation, work through the relevant item below.

<AccordionGroup>

  <Accordion title="Installation reports that Git is missing">
    Follow [Install Git](#install-git) above, restart your terminal, and verify that `git --version` succeeds before retrying the installation command.
  </Accordion>

  <Accordion title="`ffmpeg` or `ffplay` is missing">
    Install an FFmpeg build that provides both commands, restart your terminal, and re-run both `ffmpeg -version` and `ffplay -version` to confirm they are on your `PATH`.
  </Accordion>

  <Accordion title="`tablesage-rpg: command not found`">
    Restart your terminal so uv's `PATH` change takes effect, or follow the `PATH` instructions that `uv tool install` printed at the end of installation.
  </Accordion>

  <Accordion title="Settings will not save">
    Check your model IDs. Each must use the `provider/model-name` form with `anthropic`, `openai`, or `gemini` as the provider. Settings moves focus to the first field with a problem.
  </Accordion>

  <Accordion title="A connection test fails but the key looks right">
    Check whether the key is coming from your shell environment rather than from TableSage's stored configuration — see [How Shell Environment Variables Override Keys](/guides/settings#how-shell-environment-variables-override-keys). An environment variable always takes precedence over a key entered in Settings.
  </Accordion>

  <Accordion title='"This workspace uses a newer settings schema."'>
    The workspace was written by a newer version of TableSage than the one you have installed. Open the workspace with that newer version, or run the update command to bring your installation up to date:

    ```sh
    uv tool install --upgrade git+https://github.com/erik-saltwell/tablesage.git
    ```
  </Accordion>

</AccordionGroup>
